# Workflow — Release

Antes da release:

- [ ] Testes automatizados passaram.
- [ ] Migrations revisadas.
- [ ] Compatibilidade backend/frontend avaliada.
- [ ] Configurações revisadas.
- [ ] Segredos não estão no repositório.
- [ ] Docker/imagens possuem versões fixadas.
- [ ] Integrações externas revisadas.
- [ ] Alterações fiscais possuem vigência e testes.
- [ ] Documentação atualizada.
- [ ] Plano de recuperação definido para alterações críticas.
