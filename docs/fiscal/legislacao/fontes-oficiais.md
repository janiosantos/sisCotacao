## Registro de fonte

Para cada regra definitiva, registrar:

- órgão;
- norma;
- número/ano;
- artigo/anexo/item;
- assunto;
- vigência;
- data de consulta;
- URL oficial;
- ato que alterou a regra, quando houver.

Fontes secundárias podem auxiliar pesquisa, mas não substituem a fonte normativa.
