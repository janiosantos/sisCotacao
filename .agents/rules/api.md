# Regras de API

- Contratos de API devem ser explícitos.
- Mudanças incompatíveis devem possuir estratégia de versionamento ou compatibilidade.
- Validação deve ocorrer no backend.
- Erros devem ser estruturados e acionáveis.
- Não expor segredos.
- Não permitir que o cliente defina livremente resultados tributários.
- Operações críticas devem possuir idempotência quando aplicável.
