# Documentação Fiscal

Esta pasta contém documentação específica do domínio fiscal.

Estrutura:

- `legislacao/` — referências e materiais normativos.
- `regras/` — regras parametrizadas e decisões.
- `cenarios/` — cenários de negócio e fiscais.
- `calculos/` — fórmulas e exemplos validados.
- `decisoes/` — decisões arquiteturais/fiscais do projeto.

Não utilizar esta pasta para armazenar segredos ou certificados.

Regras normativas devem ser conferidas em fonte oficial antes de serem consideradas definitivas.
