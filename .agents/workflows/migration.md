# Workflow — Migration

1. Identificar mudança.
2. Avaliar compatibilidade.
3. Criar migration.
4. Testar em banco limpo.
5. Testar upgrade sobre banco existente.
6. Avaliar dados históricos.
7. Avaliar rollback/recuperação.
8. Atualizar código.
9. Executar testes.
10. Documentar qualquer mudança incompatível.

Preferir estratégia Expand → Migrate → Switch → Cleanup.
