# Regras de Segurança

- Nunca versionar senhas, tokens, certificados ou chaves privadas.
- Segredos devem vir de mecanismo seguro de configuração.
- Permissões devem ser verificadas no backend.
- Alterações fiscais críticas exigem autorização e auditoria.
- Logs não devem registrar segredos.
- Princípio do menor privilégio.
- Dados sensíveis devem ser tratados conforme necessidade e legislação aplicável.
