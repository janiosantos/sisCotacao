# Frontend

Exibir claramente se um valor vem do Produto, da Variação, de uma regra contextual ou do cálculo do documento. Destacar vigência, fonte, warnings e bloqueios.

Não permitir edição ambígua de valores calculados. Pedir confirmação para publicar regras e mostrar impacto estimado. Validar UX com estados vazios, erro, falta de parametrização, conflito e permissões insuficientes.
