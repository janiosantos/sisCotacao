# Atalhos do PDV

Os atalhos reduzem dependência do mouse. O foco visível deve permanecer no
controle ativo, inclusive em modais de desconto e cliente.

| Tecla | Ação |
|---|---|
| `Ctrl+K` | Voltar para pesquisa de produto |
| `Enter` | Adicionar sugestão ou seguir o fluxo |
| `F1` | Imprimir cupom |
| `F2` | Visualizar pedido |
| `F3` | Finalizar |
| `F5` | Novo/limpar venda |
| `F6` | Buscar cliente |
| `F7` | Configurar impressora |
| `F8` | Localizar orçamentos |
| `Delete` | Remover linha selecionada |
| `Escape` | Fechar modal/menu |

## Fluxo Enter

Com descrição vazia, `Enter` leva a **Desconto → Condição de pagamento →
Observação → Finalizar**. Se houver sugestões de produto, o primeiro Enter
seleciona o item e preserva a operação de pesquisa.

## Acessibilidade

Tabelas e listboxes devem seguir navegação por teclado, foco visível, seleção
sem depender de cor e comportamento equivalente em desktop/tablet/mobile.
