# Cenários Fiscais

Documentar cenários representativos do ERP, por exemplo:

- venda interna no Simples;
- venda interna com ST;
- venda no regime normal;
- compra interestadual;
- uso/consumo;
- ativo imobilizado;
- venda interestadual;
- consumidor final;
- contribuinte;
- devolução;
- transferência.

Cada cenário deve indicar entradas e resultado esperado, quando validado.
