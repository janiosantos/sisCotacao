# Decisões Fiscais e Arquiteturais

Registrar decisões relevantes usando, preferencialmente:

- Data
- Contexto
- Problema
- Alternativas
- Decisão
- Justificativa
- Impactos
- Referências

Exemplos:

- separação entre produto e contexto fiscal;
- versionamento de regras;
- snapshot fiscal;
- política de arredondamento;
- tratamento de conflitos.
