# Legislação

Registrar referências oficiais utilizadas na implementação fiscal.

Para cada referência relevante, preferir registrar:

- órgão;
- norma;
- número;
- ano;
- artigo/anexo/item;
- assunto;
- vigência;
- URL oficial;
- data de consulta.

Não copiar legislação integralmente para o repositório quando uma referência for suficiente.
